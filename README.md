**Admin dashboard** for the 2Again recommerce platform with AWS and chatbot integration.

## Features

- Platform analytics and KPI dashboard
- User and seller management
- BotMan chatbot for automated customer support
- AWS integration for file storage
- Transaction and payout oversight
- Listing moderation and approval

## Getting Started

```bash
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate && php artisan serve
```
